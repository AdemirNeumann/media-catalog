# Media Catalog


## Sobre o projeto

Media Catalog é uma plataforma para organização, gerenciamento e acompanhamento de conteúdos multimídia.

O sistema foi projetado para catalogar diferentes tipos de mídia como filmes, animes, donghuas, manhuas e livros, utilizando uma arquitetura escalável que permite adicionar novas categorias futuramente.

## Arquitetura

O sistema utiliza uma arquitetura separada entre frontend e backend.

Frontend:
Responsável pela interface e experiência do usuário.

Backend:
Responsável pelas regras de negócio, autenticação e comunicação com o banco de dados.

Banco:
Responsável pelo armazenamento persistente das informações.
