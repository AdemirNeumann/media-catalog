# Media Catalog

Sistema profissional para organização e gerenciamento de conteúdos multimídia.

## Objetivo

Criar uma plataforma escalável para catalogar:

- Filmes
- Animes
- Donghuas
- Manhuas
- Livros

## Tecnologias

Frontend:
- Next.js
- React
- TypeScript

Backend:
- NestJS
- TypeScript

Banco:
- PostgreSQL
- Prisma

## Status

Projeto em desenvolvimento.
